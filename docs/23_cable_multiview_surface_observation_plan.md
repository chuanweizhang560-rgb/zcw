# Cable Multiview Surface Observation Plan

This document defines the next project direction for cable surface coverage.

It does not implement multiview flight. It does not approve active control. It does not claim final cable inspection coverage.

## 2. Recommended Near-Term Claim

For the current Gazebo/PX4 project stage, the recommended near-term claim is:

```text
visible_side_cable_surface_observation_candidate=true
full_cable_surface_coverage=false
```

Reason:

- It matches the current single-side offset path.
- It is simpler to verify offline.
- It avoids pretending that one side of the cable covers the whole cylinder.
- It keeps active-control risk lower.

## 3. Full-Surface Upgrade Path

A future full-surface cable coverage experiment needs multiview observation.

Candidate views around each cable centerline:

| View | Camera Offset | Purpose |
|---|---|---|
| side A | `-Y 5m` | current accepted visible-side candidate |
| side B | `+Y 5m` | opposite side of cable |
| high/above | `+Z 5m` | top-side surface |
| low/below | `-Z 5m` | underside surface, requires safety review |

The low/below view may be unsafe or unnecessary depending on the cable height, vehicle clearance and camera mounting. It must remain a future review item.

## 4. Required Offline Work Before Flight

Before any multiview active run:

1. Generate a multiview pose candidate CSV from accepted cable centerline points.
2. Run a union-based FOV surface coverage model.
3. Check per-view trajectory continuity and transition segments.
4. Mark unsafe views as disabled if they violate clearance or camera attitude limits.
5. Decide whether the experiment claim is visible-side or full-surface.

All of this can be done offline before Gazebo active control.

## 5. Camera And Attitude Feasibility

The current surface-observation candidate assumes the camera can point at the cable.

Before using multiview views, verify:

- camera optical axis relative to vehicle body.
- allowed yaw/pitch attitude.
- whether vertical top/bottom views are physically meaningful for the PX4 `iris_depth_camera` model.
- whether the view can be generated by vehicle attitude alone or needs a gimbal.

Do not silently assume a gimbal exists.
